# SortedLinkedList

A PHP library implementing a **sorted linked list**. Supports either `int` or `string` values (not both) and keeps elements in sorted order automatically.

---

## Features

- Insert, remove, and check elements.
- Get count of elements.
- Convert to array.

---

## Installation

Clone and install dependencies:

```bash
git clone https://github.com/udanieb/sorted-linked-list.git
cd sorted-linked-list
